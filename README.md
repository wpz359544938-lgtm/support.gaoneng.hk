# Gonengo 扫码落地页

老外扫包装二维码后打开的英文页面：**联系客服 + 亚马逊店铺**两个入口。

- 文件：`index.html`（单文件，零依赖，不联网也能打开，直接上传即可）
- 适老化不用管，移动端优先：手机竖屏首屏就能看到两个按钮

## 一、你只需要改两处

用记事本 / VS Code 打开 `index.html`，用 Ctrl+F 搜索：

| 要改什么 | 搜索关键词 | 出现位置 |
| --- | --- | --- |
| 客服邮箱 | `support@gonengo.com` | 4 处（按钮里的 mailto、按钮下方可见文字、页脚） |
| 亚马逊店铺链接 | `amazon.com/stores` | 1 处（`<a class="btn btn--amazon" href="...">`） |

> 邮箱记得**全部**替换成你自己的（比如 `service@gonengo.com`），否则点按钮会发到一个不存在的地址。

## 二、怎么让它变成一个网址（给二维码用）

按省事程度排序：

1. **Netlify Drop**（最快，2 分钟）
   打开 https://app.netlify.com/drop ，把整个文件夹拖进去 → 立刻得到一个 `xxx.netlify.app` 网址，可绑定自己的域名。
2. **Cloudflare Pages / Vercel**：同样拖拽或连 GitHub，免费且国内访问比 Netlify 稍稳。
3. **GitHub Pages**：适合你想留着版本管理，免费。
4. **已有官网/服务器**：把 `index.html` 传到网站根目录的一个子目录，比如 `https://你的域名/qr/`。

上线后**一定用手机真实扫一遍**：两个按钮都要点一次，确认邮件能发出、亚马逊能打开。

## 三、二维码

二维码里要放的是**最终网址**（不是文件路径），建议加个参数方便统计来源，例如：

```
https://你的域名/qr/?src=box-a
```

页面不会因为参数变化，可放心加。需要的话告诉我网址，我给你出 PNG + SVG 两种（含白边、高纠错等级 H，覆膜/深色包装也能扫）。

## 四、页面里已经做好的细节

- 邮件按钮**自动填好主题和正文**（"Hi Gonengo team, I scanned the code on my package…"），老外点开只管写问题，回复率更高
- 邮箱文字可**点击复制**（方便在电脑上复制到别的邮箱里发）
- 亚马逊按钮新窗口打开，带外链图标
- 深色按钮 + 亚马逊橙按钮，两个入口权重相同，互不抢
- 适配 iPhone 刘海屏、深色模式强制浅色（包装页统一白底更稳）
- 支持减少动效的系统设置（无障碍）
